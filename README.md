# Daily Chain

A strict daily routine and workout challenge tracker. Installs on an iPhone Home Screen and works offline.

- Records and selfies are stored on the device (IndexedDB). Nothing is sent anywhere.
- Back up from History, under Settings, with Export backup. Restore from the same place.
- Miss a calendar day and the challenge resets to Day 1.

Install: open the site in Safari, tap Share, then Add to Home Screen.
